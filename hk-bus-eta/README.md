# 香港巴士到站時間查詢 (簡易版)

純前端香港巴士路線查詢工具，支援 **九巴 / 龍運 / 城巴**。

## 功能

1. **輸入路線號碼** → 同時查詢九巴與城巴
2. **方向按「起點 → 終點」合併**（聯營線只顯示兩個方向按鈕）
3. **車站列表**標示「九巴 / 城巴 / 共同」
4. **點擊車站**展開最近到站時間，並標示該班車屬於哪家公司
5. **右下角 🗺️** 進入計算車程（起點／終點連動篩選）
6. 路線輸入與方向按鈕在查詢後保持顯示，方便切換

## 使用方法

直接打開 `index.html`（需連網），或部署到 GitHub Pages。

## 技術

- 純 HTML + CSS + JavaScript
- 九巴 / 龍運：`data.etabus.gov.hk`
- 城巴：`rt.data.gov.hk/v2/transport/citybus`
- 車程估算：`timeinterval.hkbuseta.com`

## 注意

- 到站時間約每 1 分鐘更新，僅供參考
- 聯營線停站以較完整的一方為主，並用標籤標示差異
- 車程為歷史平均估算
