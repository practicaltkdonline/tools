# 香港巴士到站時間查詢 (簡易版)

一個簡單、純前端的香港巴士（九巴 / 龍運）路線查詢工具。

## 功能

1. **輸入路線號碼** → 自動找出兩個方向的終點站讓你選擇
2. **選擇方向後** → 顯示該方向所有車站（支援下拉選單 + 點選列表）
3. **選擇車站後** → 顯示最近 **3 個**預計到站時間

## 使用方法

直接打開 `index.html` 即可使用（需連網）。

或部署到 **GitHub Pages**：

1. 建立新 Repository
2. 把本資料夾所有檔案上傳
3. 到 Settings → Pages → Source 選 `main` branch / root
4. 等待幾分鐘後即可用 `https://你的帳號.github.io/倉庫名稱/` 開啟

## 技術

- 純 HTML + CSS + JavaScript（無框架、無建置）
- 資料來源：[DATA.GOV.HK](https://data.gov.hk) 九巴 / 龍運開放 API
  - `https://data.etabus.gov.hk/v1/transport/kmb`

## 注意事項

- 目前只支援 **九巴 (KMB)** 及 **龍運 (LWB)** 路線
- 到站時間約每 1 分鐘更新，僅供參考
- 部分特殊服務類型或臨時改道可能顯示不完整
- 建議用手機瀏覽器開啟以獲得較佳體驗
