使用說明

  1. 用 Chrome / Edge 開啟本頁（本地用 localhost 或部署到 GitHub Pages）。
  2. 點「請求通知權限」→ 允許。
  3. 點「訂閱 Push 通知」。
  4. 複製訂閱 JSON，之後可用後端（web-push）發送測試。
  5. iOS：必須先「加入主畫面」再從主畫面圖示開啟，才能正常請求權限。
